설치 안내 페이지 방문

확장 프로그램을 처음 설치하면 GitHub Pages 설치 안내 페이지가 새 탭으로 열립니다. 계정 연결 중 보조 프로그램과 통신할 수 없을 때도 같은 안내를 열 수 있습니다. 업데이트나 브라우저 재시작만으로 반복해서 열지 않습니다. 안내 주소에 인증 토큰, 이메일, 번역 페이지 주소나 본문을 넣지 않습니다. GitHub Pages는 방문 IP 및 일반 HTTP 요청 정보를 처리할 수 있습니다. 자동 다운로드나 설치 파일 실행은 하지 않습니다. GitHub 개인정보 안내를 확인하세요.

자동 번역 동의

상시 번역과 사이트 자동 번역은 사용자가 직접 켜는 선택 기능입니다. 옵션 옆에 OpenAI 전송 사실을 안내합니다. 켠 범위에서 새 콘텐츠와 이동한 페이지가 매번 버튼을 누르지 않아도 전송될 수 있습니다. 중단으로 상시 번역을 끄고 사이트 자동 번역은 해당 옵션에서 해제할 수 있습니다. 외국어 감지는 로컬에서 수행하며 안내만으로 모델을 호출하지 않습니다.

인증 정보는 사용자의 컴퓨터에서 OS 기반 암호화 방식으로 보호합니다. 이 Windows 배포본은 현재 사용자 DPAPI를 활용합니다. 프로필·설정 등 모든 로컬 파일이 암호화되는 것은 아닙니다. 인증 토큰은 확장 프로그램이나 웹페이지에 전달하지 않습니다. 확장 프로그램과 보조 프로그램은 허용된 확장 ID를 지정한 Native Messaging으로 통신합니다.

사용자 데이터는 번역과 계정 연결 등 명시된 기능 제공에만 사용하며, 판매하거나 광고 타기팅·신용평가에 사용하지 않습니다. GPT Page Translator의 데이터 이용은 Chrome Web Store 사용자 데이터 정책의 제한적 사용 요구사항을 준수하도록 운영합니다.
