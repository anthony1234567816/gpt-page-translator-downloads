도움이 더 필요하신가요? ↗
무료로 사용할 수 있나요?+

확장과 보조 프로그램은 개인·비상업적 용도로 무료 제공됩니다. 다만 번역에는 별도의 지원되는 ChatGPT Plus 또는 Pro 구독과 GPT-6 Luna 모델 사용 권한이 필요합니다. 무료 ChatGPT 계정은 지원하지 않습니다.

왜 Windows 보조 프로그램이 필요한가요?+

공식 ChatGPT 인증, 로컬 인증 정보 보호, 번역 요청 처리를 담당합니다. 확장과 Native Messaging으로 통신하며, 인증 토큰을 웹페이지나 확장에 전달하지 않습니다.

ChatGPT Plus 또는 Pro만 있으면 되나요?+

지원되는 Plus/Pro 계정, GPT-6 Luna 모델 접근 권한과 공식 플랜 사용 승인이 필요합니다. 계정의 사용량 제한이 적용되며 무제한 번역을 보장하지 않습니다.

OpenAI API 키를 따로 구매해야 하나요?+

별도 API 키는 필요하지 않습니다. 공식 Sign in with ChatGPT로 본인 계정을 연결합니다.

Chrome과 Comet에서 모두 쓸 수 있나요?+

Windows 10/11 x64의 Google Chrome과 Comet을 지원합니다. 사용할 브라우저에서 확장을 설치하고, 보조 프로그램에서 같은 브라우저를 선택해 연결하세요.

Mac에서도 사용할 수 있나요?+

macOS는 개발 환경에서 연결을 확인한 단계입니다. 일반 사용자용 DMG는 아직 출시하지 않았으며, 현재 제공하는 Windows EXE는 Mac에서 실행할 수 없습니다.

웹페이지 데이터는 어떻게 처리되나요?+

번역 대상 텍스트와 주변 문맥은 OpenAI로 전송됩니다. 사이트 자동 번역·상시 번역을 켜면 새 콘텐츠나 설정 범위의 페이지도 매번 클릭 없이 전송될 수 있습니다. 자세한 내용은 개인정보처리방침을 확인하세요.

설치했는데 연결되지 않으면 어떻게 하나요?+

연결 도구에서 사용할 브라우저를 다시 선택해 연결하고 브라우저를 완전히 재시작하세요. 설치·문제 해결 안내에서 재연결 경로와 진단 방법을 확인할 수 있습니다.
