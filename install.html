현재 베타는 Apple Developer ID 서명·공증 전입니다. 공식 출처와 SHA-256을 확인하고, 실행을 시도한 뒤 시스템 설정 → 개인정보 보호 및 보안에서 실행 허용 여부를 확인하세요. macOS 버전에 따라 ‘확인 없이 열기’ 또는 ‘Open Anyway’로 표시될 수 있습니다. 손상 또는 악성코드 경고를 같은 이유로 단정하지 마세요.

현재 사용자 계정에 설치하며, 인증 정보 보호를 위한 Keychain 접근 과정에서 Mac 로그인 암호나 허용을 요청할 수 있습니다. 요청은 여러 번 나타날 수 있으니 창에 표시된 앱과 요청 내용을 확인해 주세요.

보조 프로그램을 설치했는데 연결되지 않아요.+

브라우저를 완전히 종료한 뒤 다시 열어보세요. 계속 안 되면 Win + R을 누르고 %LOCALAPPDATA%\GPT Page Translator를 입력하세요. App\windows\Install.cmd를 실행해 같은 브라우저를 선택하고 브라우저 연결을 누릅니다. 이 도구는 연결만 처리하며 재설치·복구는 다운로드한 EXE에서 진행합니다.

다른 브라우저를 선택한 것 같아요.+

Chrome을 쓴다면 Google Chrome을, Comet을 쓴다면 Comet을 선택해야 합니다. 두 브라우저를 모두 사용하면 각각 연결하세요. 확장 프로그램도 사용할 브라우저에 설치되어 있어야 합니다.

연결 확인이 오래 걸려요.+

파일과 로컬 연결을 확인하는 동안 30초~1분 이상 걸릴 수 있습니다. v1.3.0의 진행 막대와 경과 시간을 확인하고 완료될 때까지 기다려 주세요. 사전 점검이 완료된 뒤 실제 연결과 번역은 브라우저 확장에서 확인합니다.

SmartScreen 또는 알 수 없는 게시자 경고가 떠요.+

현재 설치 EXE는 코드 서명되지 않았습니다. 공식 배포처와 SHA-256을 확인하고 Windows 보안으로 파일을 검사하세요. 회사·학교 정책으로 차단되면 관리자에게 문의하세요. 보안 기능을 끄거나 백신 탐지를 우회해 실행하지 마세요.

프로그램을 복구하거나 다시 설치하고 싶어요.+

브라우저를 종료하고 설치 EXE를 다시 실행하세요. 상태에 따라 재설치·업데이트·복구를 선택할 수 있습니다. 더 최신 버전이 이미 설치되어 있으면 해당 설치 파일로 다운그레이드할 수 없습니다.

제거하면 로그인 정보도 지워지나요?+

기본 제거는 ChatGPT 인증 정보와 기존 개발자 확장 폴더를 보존합니다. 완전 삭제를 직접 선택하고 확인하면 인증·계정 데이터와 기존 확장 파일, 알려진 진단 로그도 삭제됩니다. 다시 로그인해야 합니다. 웹스토어 확장과 브라우저 설정은 별도이며 원격 ChatGPT 승인 해제는 보장하지 않습니다.

이전 개발자 모드 버전에서 바꾸려면요?+

v1.3.0 업데이트는 기존 App\extension을 같은 위치에 보존합니다. 번역 속도·자동 사이트 등 설정을 기록한 뒤 웹스토어 버전으로 전환하세요. 개발자 확장을 제거하면 브라우저 설정이 초기화될 수 있습니다. 서로 다른 ID의 이전 확장과 스토어 확장을 동시에 켜지 마세요.

어떤 정보를 보내면 도움을 받을 수 있나요?+

Windows·브라우저·보조 프로그램 버전과 오류 코드를 알려주세요. 설치 로그는 %LOCALAPPDATA%\GPT Page Translator\installer-log.jsonl, 연결 점검 진단은 같은 폴더의 connection-check-result.txt입니다. 비밀번호·인증 파일·토큰·개인 웹페이지 본문은 보내지 마세요.

다운로드 출처와 파일을 확인하세요.

공식 GitHub Release와 체크섬을 기준으로 확인하세요. SHA-256 확인 예시:

Get-FileHash -Algorithm SHA256 "다운로드한 파일 경로"

보조 프로그램 v1.3.0의 파일과 SHA-256은 GitHub Release에서 확인할 수 있습니다.
