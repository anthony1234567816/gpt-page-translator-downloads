GPT Page Translator 설치 및 지원

GPT-6 Luna로 웹페이지를 한국어로 번역합니다. 확장 프로그램과 로컬 보조 프로그램을 모두 설치해야 합니다. 개인·비상업적 테스트 배포입니다. ChatGPT 및 모델 접근 권한과 플랜 사용 승인이 필요하며 사용량 제한이 적용됩니다. 무료 계정 사용을 보장하지 않습니다.

지금은 미등록 테스트 배포 준비 중

웹스토어 항목은 아직 초안이며 심사 전입니다. 웹스토어 설치 링크는 게시 후 작동합니다. 게시 후에는 링크를 아는 누구나 설치할 수 있습니다. 스토어 이용 시 보조 프로그램에 ID를 입력하지 않습니다.

Windows 10/11 x64

1. 설치 파일을 내려받아 실행합니다. Node.js는 포함되어 있습니다.

2. 준비 진행률과 프로그램 파일 설치가 끝날 때까지 기다립니다.

3. 사용할 브라우저를 선택하고 연결를 누릅니다. 고정 확장 ID가 이미 포함되어 있습니다.

4. 게시 후 웹스토어에서 확장 프로그램을 설치합니다. 보조 프로그램과 확장의 설치 순서는 바뀌어도 됩니다.

5. 브라우저를 다시 열고 확장 팝업에서 ChatGPT 연결을 선택합니다. 본인 계정으로 공식 OpenAI 로그인과 플랜 사용 승인을 진행합니다.

6. 일반 영어·일본어 웹페이지에서 한국어로 번역을 누릅니다.

현재 설치 파일은 코드 서명되지 않았습니다. Windows가 보안 안내를 표시할 수 있습니다. 원본 다운로드 경로와 SHA256을 확인하고 시스템 보안 기능을 끄지 마세요. 정책상 실행이 차단된 기기에서는 관리자에게 문의해 주세요.

웹스토어 게시 전 수동 테스트

배포 ZIP을 압축 해제한 뒤 Comet/Chrome의 chrome://extensions에서 개발자 모드를 켜고 ZIP 안의 extension 폴더를 로드합니다. 표시되는 ID는 nfgonbjadjmfjcickpocfhgefhbcdegk여야 합니다. 기존 개발용 확장은 꺼서 중복 실행을 피합니다. 새 설치 파일은 기존 Native Messaging 등록을 이 고정 ID로 교체합니다.

macOS (터미널 설치)

1. 공식 https://nodejs.org/ 에서 Node.js 22.12 이상을 설치합니다.

2. 터미널에서 xcode-select --install로 Command Line Tools를 설치합니다. 이미 설치했다면 생략합니다.

3. Mac 배포 ZIP을 압축 해제해 계속 보관할 폴더에 둡니다. 설치 후 이 폴더를 이동·삭제하면 연결이 끊깁니다.

4. 터미널에서 압축 해제한 프로젝트 폴더로 이동합니다.

chmod +x install-host.sh
./install-host.sh comet nfgonbjadjmfjcickpocfhgefhbcdegk

Chrome이면 comet을 chrome으로 바꿉니다. sudo는 필요하지 않습니다. npm 의존성 다운로드에 인터넷 연결이 필요합니다. 웹스토어 게시 전에는 포함된 extension 폴더를 개발자 모드로 로드합니다. 게시 뒤에는 웹스토어 확장을 설치합니다. 기존 개발용 확장은 중복 실행하지 마세요.

브라우저를 다시 시작하고 확장 팝업에서 본인의 ChatGPT 계정을 연결합니다. 운영체제의 자격 증명 저장 기능을 사용하며 별도의 로컬 번역 엔진은 없습니다.

사용 방법

  • 한국어로 번역: 현재 페이지에서 시작합니다. 읽는 화면을 우선 처리하고 배치 응답을 스트리밍으로 표시합니다.
  • 중단: 실행 중인 요청을 취소하며 이미 적용된 번역은 유지합니다.
  • 원문 복원: 번역 요청을 취소하고 원문을 복원합니다.
  • 다시 번역: 페이지 번역을 다시 시작합니다. 남아 있는 캐시는 사용될 수 있습니다.
  • 상시 번역: 사이트 이동과 추가 콘텐츠도 계속 번역합니다. 중단하면 꺼집니다.
  • 사이트 자동 번역: 지정한 사이트를 방문할 때 번역을 시작합니다.
  • 속도: 느림·보통·빠름·매우 빠름. 동시 요청 증가가 항상 더 빠른 결과를 보장하지는 않습니다.

자동 번역을 켠 페이지의 새 콘텐츠도 OpenAI로 전송될 수 있습니다. 개인 메시지나 민감한 페이지는 번역 전에 확인하세요.

연결·오류 해결

  • 연결 실패: 브라우저를 다시 시작하고 확장 ID가 위의 ID인지 확인합니다. 지원되지 않는 플랫폼이나 보조 프로그램 미설치 시 연결할 수 없습니다.
  • 플랜 승인 필요: 공식 로그인에서 플랜 사용 승인을 완료합니다. 다른 계정 연결 기능으로 계정을 선택할 수 있습니다.
  • 사용량 제한: 자동 재요청을 반복하지 않습니다. 계정의 사용 가능 상태가 회복된 뒤 사용자가 다시 실행합니다.
  • 번역되지 않음: PDF·브라우저 내부 페이지·코드 블록·입력 필드·이미지 속 텍스트는 대상이 아닙니다. 일부 웹사이트의 구조에 따라 제한될 수 있습니다.

업데이트·제거

업데이트 전 번역을 중단하고 브라우저를 종료합니다. Windows는 새 설치 파일을 실행합니다. Mac은 기존 폴더 경로를 유지해 교체하고 설치 명령을 다시 실행합니다. 웹스토어 게시 후 확장 업데이트는 스토어를 통해 제공되며, 보조 프로그램은 별도로 업데이트합니다.

제거 전 계정 연결을 해제하고 브라우저에서 확장을 제거합니다. Windows 보조 프로그램은 %LOCALAPPDATA%\GPT Page Translator\App\windows\Uninstall.cmd를 실행해 제거합니다. 저장된 로그인 데이터는 자동 삭제되지 않으므로 완전 삭제가 필요하면 개인정보처리방침의 데이터 폴더 안내를 확인하세요. Mac 제거 방법은 배포 ZIP의 Mac-터미널-설치안내.md를 따릅니다.
